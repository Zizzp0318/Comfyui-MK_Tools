# MK-图像裁剪节点文档

## 概述

MK-图像裁剪节点用于根据指定的宽度、高度、位置和偏移量裁剪图像。该节点从 ComfyUI_essentials 项目迁移而来（原始节点名称：🔧 Image Crop）。

## 节点信息

- **节点类名**: `MK_ImageCrop`
- **显示名称**: MK-图像裁剪
- **分类**: MK_Tools/image
- **源文件**: `nodes/image_crop.py`

## 输入参数

### 必需输入

| 参数名 | 类型 | 默认值 | 范围 | 说明 |
|--------|------|--------|------|------|
| image | IMAGE | - | - | 输入图像 |
| width | INT | 256 | 0 - MAX_RESOLUTION | 裁剪宽度（步长：8） |
| height | INT | 256 | 0 - MAX_RESOLUTION | 裁剪高度（步长：8） |
| position | STRING | - | 见下方 | 裁剪位置 |
| x_offset | INT | 0 | -99999 - ∞ | X轴偏移量 |
| y_offset | INT | 0 | -99999 - ∞ | Y轴偏移量 |

### 位置选项 (position)

- `top-left` - 左上角
- `top-center` - 上方居中
- `top-right` - 右上角
- `right-center` - 右侧居中
- `bottom-right` - 右下角
- `bottom-center` - 下方居中
- `bottom-left` - 左下角
- `left-center` - 左侧居中
- `center` - 中心

## 输出

| 输出名 | 类型 | 说明 |
|--------|------|------|
| IMAGE | IMAGE | 裁剪后的图像 |
| x | INT | 裁剪起始点的X坐标 |
| y | INT | 裁剪起始点的Y坐标 |

## 功能说明

该节点可以对图像进行精确裁剪，支持以下特性：

1. **智能尺寸调整**：如果指定的裁剪尺寸超过原图尺寸，会自动调整为原图尺寸
2. **灵活定位**：支持9个预设位置，可以快速定位裁剪区域
3. **精确偏移**：通过 x_offset 和 y_offset 可以对裁剪位置进行微调
4. **边界保护**：自动处理边界情况，确保裁剪区域始终在图像范围内
5. **坐标输出**：返回实际裁剪位置的坐标，便于后续处理

## 使用示例

### 示例1：居中裁剪

```
输入:
- image: 1920x1080 的图像
- width: 512
- height: 512
- position: center
- x_offset: 0
- y_offset: 0

输出:
- IMAGE: 512x512 的裁剪图像
- x: 704 (居中位置)
- y: 284 (居中位置)
```

### 示例2：左上角裁剪并偏移

```
输入:
- image: 1920x1080 的图像
- width: 512
- height: 512
- position: top-left
- x_offset: 100
- y_offset: 50

输出:
- IMAGE: 512x512 的裁剪图像
- x: 100 (左上角 + x偏移)
- y: 50 (左上角 + y偏移)
```

### 示例3：右下角裁剪

```
输入:
- image: 1920x1080 的图像
- width: 512
- height: 512
- position: bottom-right
- x_offset: -50
- y_offset: -30

输出:
- IMAGE: 512x512 的裁剪图像
- x: 1358 (右下角 - x偏移)
- y: 538 (右下角 - y偏移)
```

## 技术细节

### 坐标计算逻辑

1. 首先根据 position 参数确定基础坐标
2. 然后应用 x_offset 和 y_offset 偏移
3. 最后进行边界检查和调整

### 边界处理

- 如果裁剪区域超出右边界，x2 被限制为图像宽度
- 如果裁剪区域超出下边界，y2 被限制为图像高度
- 如果起始坐标为负，被限制为 0

### 批处理支持

该节点支持批处理，可以对批次中的所有图像应用相同的裁剪参数。

## 应用场景

1. **图像预处理**：为AI模型准备固定尺寸的输入
2. **焦点提取**：从大图中提取感兴趣区域
3. **构图调整**：对图像进行重新构图
4. **批量裁剪**：对多张图像进行统一裁剪
5. **区域分析**：提取图像的特定区域进行分析

## 注意事项

1. width 和 height 的步长为 8，这是为了兼容某些需要 8 的倍数尺寸的模型
2. 偏移量可以为负值，用于反向偏移
3. 返回的 x, y 坐标是经过边界检查后的实际裁剪位置
4. 如果偏移量过大导致裁剪区域完全超出边界，节点会自动调整到有效范围

## 与原始节点的兼容性

该节点完全保持了 ComfyUI_essentials 中 ImageCrop+ 节点的功能和参数，可以无缝替换原节点使用。
