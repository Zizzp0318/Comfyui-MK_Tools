## 功能特性

### 输入参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| image | IMAGE | - | 输入图像 |
| width | INT | 256 | 裁剪宽度 (步长8) |
| height | INT | 256 | 裁剪高度 (步长8) |
| position | STRING | - | 9种位置选项 |
| x_offset | INT | 0 | X轴偏移 |
| y_offset | INT | 0 | Y轴偏移 |

### 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| IMAGE | IMAGE | 裁剪后的图像 |
| x | INT | 实际裁剪X坐标 |
| y | INT | 实际裁剪Y坐标 |

### 位置选项

```
top-left      top-center      top-right
left-center      center      right-center
bottom-left   bottom-center   bottom-right
```
